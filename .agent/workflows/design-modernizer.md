# design-modernizer

This workflow is for auditing and refactoring existing projects that look "generic" or suffer from "AI slop."

## Steps

### Step 1: The Design Audit
Invoke the **Anti-Slop Auditor** to scan the codebase.
- **Goal**: Identify generic fonts, oversaturated colors, and weak layouts.
- **Skill**: `redesign-skill`
- **Output**: A list of specific design "offenses" to fix.

### Step 2: Select a Style Paradigm
Choose a high-end aesthetic direction based on the audit.
- **Options**: 
    - **Soft UI**: Use `soft-skill`.
    - **Minimalist**: Use `minimalist-skill`.
    - **Brutalist**: Use `brutalist-skill`.

### Step 3: Targeted Refactor
Invoke the **Frontend Specialist** or **UI/UX Pro Max** to apply the fixes.
- **Goal**: Replace generic patterns with premium ones.
- **Focus**: Typography scale, whitespace, and interaction states.

### Step 4: Motion Injection
Invoke the **Awwwards Motion Engineer**.
- **Goal**: Add subtle, physics-based micro-interactions to make the UI feel alive.

## Checklist
- [ ] All "Inter" font instances replaced?
- [ ] Palette desaturated and disciplined?
- [ ] Interactive states (hover/active/loading) added?
- [ ] Layout asymmetry introduced?

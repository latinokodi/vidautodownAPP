# brand-to-build

This workflow takes a new product from zero to a world-class branded implementation. It ensures that the visual soul of the brand is perfectly translated into the final code.

## Steps

### Step 1: Establish the Visual Soul
Invoke the **Brand & Identity Strategist** to create the core identity.
- **Goal**: Generate a premium brand kit image.
- **Skill**: `brandkit`
- **Output**: Logo, palette, and typography system.

### Step 2: Codify the Design Rules
Invoke the **Brand & Identity Strategist** to translate the visual identity into code rules.
- **Goal**: Generate a `DESIGN.md` file.
- **Skill**: `stitch-skill`
- **Output**: Semantic design tokens and anti-patterns.

### Step 3: Create Visual References
Invoke the **Visual Prototyping Lead** to design the site sections.
- **Goal**: Generate section-by-section high-fidelity images.
- **Skill**: `imagegen-frontend-web`
- **Output**: Clear visual source of truth for every part of the site.

### Step 4: Premium Implementation
Invoke the **Awwwards Motion Engineer** and **Frontend Specialist** to build the site.
- **Goal**: Implement the site with GSAP animations and pixel-perfect fidelity.
- **Skills**: `gpt-taste`, `taste-skill`
- **Constraint**: No truncation, no placeholders (`output-skill`).

## Checklist
- [ ] Brand kit reflects the product metaphor?
- [ ] DESIGN.md contains specific tokens?
- [ ] Every section has a high-fidelity reference image?
- [ ] Implementation includes physics-based motion?

# mobile-first-vision

This workflow focuses on rapid high-fidelity prototyping for mobile applications, emphasizing native feel and flow logic.

## Steps

### Step 1: Design the Screen Flows
Invoke the **Visual Prototyping Lead** to create the app journey.
- **Goal**: Generate multiple screen images (onboarding, home, detail).
- **Skill**: `imagegen-frontend-mobile`
- **Output**: Consistent app screens inside premium device mockups.

### Step 2: Detail Refinement
Invoke the **Visual Prototyping Lead** for complex areas.
- **Goal**: Generate detail renders of specific components (charts, forms).
- **Output**: Clear analysis of component states.

### Step 3: Implementation Strategy
Invoke the **Mobile Developer** or **Android Engineer**.
- **Goal**: Implement the screens in React Native, Flutter, or Native code.
- **Analysis**: Use the generated images as the absolute source of truth for spacing and type.

## Checklist
- [ ] All screens follow a logical user journey?
- [ ] Design remains consistent across all images?
- [ ] Safe areas and system regions respected?
- [ ] Mockup framing is clean and professional?

# Color Palette Reference

Complete database of 97 color palettes organized by product type and mood.

## Color Roles

Every palette includes:
- **Primary:** Main brand color, CTAs, key actions
- **Secondary:** Supporting elements, accents
- **Background:** Page/section backgrounds
- **Surface:** Card/component backgrounds
- **Text:** Primary text color
- **Text Muted:** Secondary text, captions
- **Border:** Dividers, outlines
- **Success:** Positive states, confirmations
- **Warning:** Cautionary states
- **Error:** Error states, destructive actions

## Accessibility Notes

### Minimum Contrast Ratios
- Normal text (14-18px): 4.5:1 minimum
- Large text (18px+ bold, 24px+ normal): 3:1 minimum
- UI components: 3:1 minimum

### Color Blindness Considerations
- Don't rely on color alone - use icons/patterns
- Red-green is most common (affects 8% males)
- Test with grayscale or simulators
- Ensure sufficient brightness contrast

### Dark Mode Best Practices
- Avoid pure black (#000000) - causes eye strain
- Use elevated surfaces (Surface 2, Surface 3) for depth
- Reduce saturation in dark mode
- Ensure text isn't too bright (avoid pure white)
